An original mobile-first **multiplayer battle-royale** with custom world, characters, weapons, vehicles, maps and backend.

**Gameplay Loop:** Land → Loot → Collect Weapons & Armor → Fight → Use Vehicles → Revive Team → Survive Zone → Win

**Modes:** Solo | Duo | Squad | Training | Custom Rooms

**Planned Features:** Third-person combat, Inventory/Loot, Healing, Vehicles, Safe Zone, Team Revive, Progression, Missions, Leaderboards, Cosmetics, Battle-Pass, Matchmaking, Stats
